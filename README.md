# The Girl Who Collected Stars

An interactive story made with Adobe Animate (HTML5 Canvas / CreateJS).

- `index.html` — the interactive story: watch the stars fall into her jar, then tap the jar to set them free.
- `ar.html` — AR mode: point your phone camera at the printed poster (MindAR image tracking).
